# Baddify

A clone of coolify, but with more features.

#### ⚠️ Currently in early stages of development, not production ready.

## Planned Features

- Edge Function Deployments
- Container Deployments
- Database Deployments
- Storage Deployments
- Database Backups
- Storage Backups
- Team Management
- Role-Based Access Control
- Two-Factor Authentication
- Activity Logs
- Audit Logs
- Webhooks
- SSH Key Management
- SSL Certificate Management
- Domain Management
- Health Monitoring
- Performance Monitoring
- Security Monitoring
- Cost Monitoring
- Alerting
- Auto-Scaling
- Auto-Healing
- Auto-Backups
- Auto-Updates
- Auto-Deployments

And more...

## Tech Stack

Frontend:
- React
- TypeScript
- Tailwind CSS
- Material UI

Backend:
- Go
- MongoDB
